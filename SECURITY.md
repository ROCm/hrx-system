# Security Policy

## Reporting a vulnerability

Do not report security vulnerabilities through public GitHub issues,
discussions, or pull requests. Report them privately through the
[AMD Product Security website](https://www.amd.com/en/resources/product-security.html).

Include the affected version or commit, the potential impact, and the smallest
available reproducer. This policy covers source code, build and release
automation, and artifacts published from this repository.
